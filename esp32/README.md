# ESP32 firmware

The firmware receives the rendered display over WebSocket and sends Spotify playback events from three buttons.

## Wiring

Use a 128×64 SSD1309 I²C OLED at address `0x3C`:

| OLED pin | ESP32 pin |
| -------- | --------- |
| VCC      | 3V3       |
| GND      | GND       |
| SDA      | GPIO 21   |
| SCL      | GPIO 22   |

The ESP32 GPIO level is 3.3 V. Power the OLED from **3.3 V**.

Connect each normally-open button between the listed GPIO and GND; the firmware uses the ESP32's internal pull-up resistors.

| Button   | GPIO | Event           |
| -------- | ---- | --------------- |
| Skip     | 32   | `skip_song`     |
| Previous | 33   | `previous_song` |
| Play     | 25   | `play_song`     |

## Configure and flash

Create `main/secrets.h` (it is ignored by Git):

```cpp
#define WIFI_SSID "your-wifi-name"
#define WIFI_PASS "your-wifi-password"
```

In `main/websocket.cpp`, change `WEBSOCKET_URI` to the LAN address of the computer/server running FastAPI, for example:

```cpp
#define WEBSOCKET_URI "ws://192.168.1.50:8000/ws"
```

From this directory, with the ESP-IDF environment loaded:

```sh
idf.py build flash monitor
```

## Dependency workaround

If the u8g2 component fails to build because it cannot find GPIO symbols, add `esp_driver_gpio` to `PRIV_REQUIRES` in `managed_components/nixy4__u8g2/CMakeLists.txt`. This directory is generated by the ESP-IDF component manager, so repeat the change after refreshing managed dependencies if necessary.
